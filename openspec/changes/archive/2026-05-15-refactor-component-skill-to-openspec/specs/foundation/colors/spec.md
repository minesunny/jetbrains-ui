## Tailwind Token Reference

These colors are exposed as Tailwind CSS custom properties in `tokens.css`. Usage pattern:

```css
/* text-gray-1 → var(--color-gray-1) */
text-gray-1
bg-blue-4
border-gray-8
ring-blue-6
```

### Common Component Mappings

| Visual Purpose | Light Token | Dark Token |
|---------------|------------|------------|
| Primary text | `text-gray-1` | `text-gray-11` |
| Secondary text | `text-gray-7` | `text-gray-7` |
| Disabled text | `text-gray-8` | `text-gray-8` |
| White text (on accent) | `text-gray-14` | `text-gray-14` |
| Primary accent bg | `bg-blue-4` | `bg-blue-6` |
| Primary hover bg | `bg-blue-3` | `bg-blue-5` |
| Primary pressed bg | `bg-blue-2` | `bg-blue-4` |
| Default border | `border-gray-8` | `border-gray-6` |
| Hover border | `border-gray-6` | `border-gray-7` |
| Focus border | `border-blue-4` | `border-blue-6` |
| Error border | `border-red-4` | `border-red-7` |
| Surface bg | `bg-gray-14` | `bg-gray-2` |
| Secondary surface | `bg-gray-13` | `bg-gray-3` |
| Hover surface | `bg-gray-12` | `bg-gray-4` |
| Focus ring | `ring-blue-4` | `ring-blue-6` |
| Error ring | `ring-red-4` | `ring-red-7` |
