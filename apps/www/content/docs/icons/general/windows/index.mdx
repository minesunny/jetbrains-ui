## Overview

A set of **16 Windows icons** from the JetBrains UI design system, provided as standalone React components with TypeScript support.

### Usage

<IconDetailPreview name="Close" category="windows" />

```tsx
import { SVG } from '@/registry/components/svg';

<SVG name="general/windows/close" />

<SVG name="general/windows/close" size="lg" />

<SVG name="general/windows/close" aria-label="Close icon" />
```
