## Overview

A set of **4 Duplicates icons** from the JetBrains UI design system, provided as standalone React components with TypeScript support.

### Usage

<IconDetailPreview name="SendToTheLeft" category="duplicates" />

```tsx
import { SVG } from '@/registry/components/svg';

<SVG name="general/duplicates/sendToTheLeft" />

<SVG name="general/duplicates/sendToTheLeft" size="lg" />

<SVG name="general/duplicates/sendToTheLeft" aria-label="SendToTheLeft icon" />
```
