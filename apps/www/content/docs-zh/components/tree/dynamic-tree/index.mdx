## 概述

`DynamicTree` 是 `@headless-tree` 的展示层封装。你自己提供 `containerProps` 和 `items`，组件只负责用 JetBrains UI 的树样式把它们渲染出来。

## 用法

```tsx
import * as React from 'react';
import {
  hotkeysCoreFeature,
  selectionFeature,
  type TreeDataLoader,
} from '@headless-tree/core';
import { useTree } from '@headless-tree/react';
import {
  type DynamicTreeItemProps,
  DynamicTree,
  asyncDataLoaderFeature,
  type DynamicTreeItemData,
} from '@/components/jetbrains-ui/tree/dynamic-tree';

type FileTreeItem = DynamicTreeItemData & {
  path: string;
  isFolder?: boolean;
};

const ROOT_ID = 'root';

const loadData = async (parentId: string | null) => {
  if (parentId === null) {
    return [
      {
        id: 'folder-src',
        data: {
          label: 'src',
          path: '/src',
          isFolder: true,
        },
      },
      {
        id: 'readme-md',
        data: {
          label: 'README.md',
          path: '/README.md',
        },
      },
    ];
  }

  if (parentId === 'folder-src') {
    return [
      {
        id: 'index-tsx',
        data: {
          label: 'index.tsx',
          path: '/src/index.tsx',
        },
      },
    ];
  }

  return [];
};

function Example() {
  const loadedItemsRef = React.useRef<Record<string, FileTreeItem>>({});
  const FileItem = React.useCallback(
    ({ item }: DynamicTreeItemProps<FileTreeItem>) => (
      <div className="flex h-6 items-center gap-2 px-4 text-[13px]">
        <span>{item.isFolder() ? 'DIR' : 'FILE'}</span>
        <span className="truncate">
          {item.getItemData()?.label ?? item.getId()}
        </span>
      </div>
    ),
    [],
  );
  const dataLoader = React.useMemo<TreeDataLoader<FileTreeItem>>(
    () => ({
      getItem: async (itemId) => {
        const [realItemId] = itemId.split('@');

        if (realItemId === ROOT_ID) {
          return {
            label: 'root',
            isFolder: true,
          } as FileTreeItem;
        }

        return (
          loadedItemsRef.current[realItemId] ??
          ({
            label: realItemId,
            path: realItemId,
          } as FileTreeItem)
        );
      },
      getChildrenWithData: async (itemId) =>
        loadData(
          itemId.split('@')[0] === ROOT_ID ? null : itemId.split('@')[0],
        ),
    }),
    [],
  );
  const tree = useTree<FileTreeItem>({
    rootItemId: ROOT_ID,
    dataLoader,
    isItemFolder: (item) => Boolean(item.getItemData()?.isFolder),
    getItemName: (item) => item.getItemData()?.label ?? item.getId(),
    onLoadedItem: (itemId, item) => {
      loadedItemsRef.current[itemId] = item;
    },
    createLoadingItemData: () => ({}) as FileTreeItem,
    features: [asyncDataLoaderFeature, selectionFeature, hotkeysCoreFeature],
  });

  return (
    <DynamicTree<FileTreeItem>
      containerProps={
        tree.getContainerProps('Tree') as React.ComponentPropsWithoutRef<'div'>
      }
      items={tree.getItems()}
      item={FileItem}
      width="220px"
      height="160px"
    />
  );
}
```

## 右键菜单

右键点击任意树节点会弹出上下文菜单。默认菜单自动启用，提供四个操作：

| 操作     | 文件夹 | 叶子节点 | 实现方式                      | 需要的 Prop  |
| -------- | ------ | -------- | ----------------------------- | ------------ |
| 新增     | 是     | 否       | 调用 `addItem` prop           | `addItem`    |
| 刷新     | 是     | 是       | 内置（使数据缓存失效）        | -            |
| 清理子项 | 是     | 否       | 内置（清除缓存 + 收起文件夹） | -            |
| 删除     | 是     | 是       | 调用 `deleteItem` prop        | `deleteItem` |

没有提供处理函数的操作在菜单中显示为**禁用**状态。

### 添加操作处理

```tsx
<DynamicTree
  containerProps={tree.getContainerProps('Tree')}
  items={tree.getItems()}
  addItem={(item) => createChildNode(item.getId())}
  deleteItem={(item) => removeNode(item.getId())}
/>
```

### 禁用右键菜单

```tsx
<DynamicTree contextMenu={null} ... />
```

### 自定义右键菜单

```tsx
import {
  ContextMenuItem,
  ContextMenuSeparator,
} from '@/components/jetbrains-ui/context-menu';

<DynamicTree
  contextMenu={(item, actions) => (
    <>
      <ContextMenuItem onSelect={() => actions.refresh(item)}>
        刷新
      </ContextMenuItem>
      <ContextMenuSeparator />
      <ContextMenuItem
        variant="destructive"
        onSelect={() => actions.delete?.(item)}
      >
        删除
      </ContextMenuItem>
    </>
  )}
  deleteItem={(item) => removeNode(item.getId())}
/>;
```

渲染函数接收 `ItemInstance` 和一个 `TreeItemActions` 对象，包含预绑定的操作：`actions.refresh(item)`、`actions.clearChildren(item)`、`actions.add?.(item)` 和 `actions.delete?.(item)`。

## 滚动

`DynamicTree` 默认已经包裹了 `ScrollArea`。通过 `width` 和 `height` 约束可视区域后，已加载节点超出空间时会自动滚动。

## API 说明

- `DynamicTree<TItem>`：展示层，负责根据 `containerProps` 和 `items` 渲染树。
- `asyncDataLoaderFeature`：推荐内置的异步 feature，支持可刷新的 item data cache。
- `item`：可以替换默认的 `DynamicTreeItem`，按你的 item 类型自定义组件。
- `contextMenu`：`undefined` 使用内置菜单（默认），`null` 禁用，或传入渲染函数 `(item, actions) => ReactNode` 自定义菜单。
- `addItem`：新增子节点的回调。由默认菜单的「新增」操作调用，自定义菜单中通过 `actions.add` 使用。
- `deleteItem`：删除节点的回调。由默认菜单的「删除」操作调用，自定义菜单中通过 `actions.delete` 使用。
- `TreeItemActions<TItem>`：传入右键菜单渲染函数的 actions 对象类型。
- `containerProps` 与 `items`：由你自己的 `@headless-tree` 配置直接提供。
- `width` 与 `height`：限制外层滚动区域尺寸，内容超出时启用滚动。
- 数据加载、选中和键盘行为由你自己定义的 `@headless-tree` 逻辑决定。
