## 概述

对话框是覆盖在主窗口之上的窗口，用于表单、确认和其他任务。
本组件基于 Radix `Dialog` 原语构建，提供可组合的 header/content/footer API。

## 安装

<ComponentInstallation name="dialog" />

## 使用

```tsx
import {
  Dialog,
  DialogClose,
  DialogContent,
  DialogDescription,
  DialogFooter,
  DialogHeader,
  DialogTitle,
  DialogTrigger,
} from '@/components/jetbrains-ui/dialog';
import { Button } from '@/components/jetbrains-ui/buttons';

<Dialog>
  <DialogTrigger asChild>
    <Button variant="secondary">Open Dialog</Button>
  </DialogTrigger>
  <DialogContent>
    <DialogHeader>
      <DialogTitle>Edit Profile</DialogTitle>
    </DialogHeader>
    <div className="px-5 py-4">
      <DialogDescription>Make changes to your profile here.</DialogDescription>
    </div>
    <DialogFooter>
      <div className="ml-auto flex items-center gap-3">
        <DialogClose asChild>
          <Button variant="secondary">Cancel</Button>
        </DialogClose>
        <DialogClose asChild>
          <Button>Save Changes</Button>
        </DialogClose>
      </div>
    </DialogFooter>
  </DialogContent>
</Dialog>;
```

## 结构

- **DialogHeader**: 顶部区域，带有 `border-bottom` 分隔线和 `rounded-t-[5px]` 圆角。包含 `DialogTitle`。
- **DialogFooter**: 底部区域，带有 `border-top` 分隔线和 `rounded-b-[10px]` 圆角。包含操作按钮。
- **DialogContent**: 根面板，`border-[0.5px]`，`rounded-lg`（8px），主题阴影。

## 样式

- 浅色模式: `bg-gray-13 border-gray-12 shadow-[var(--shadow-dialog)]`
- 深色模式: `dark:bg-gray-2 dark:border-gray-3 dark:shadow-[var(--shadow-dialog-dark)]`
- 头部边框: `border-gray-12` / `dark:border-gray-3`
- 底部边框: `border-gray-12` / `dark:border-gray-3`
