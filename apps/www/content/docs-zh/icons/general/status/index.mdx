## Overview

来自 JetBrains UI 设计系统的 **13 个 Status 图标**，以独立 React 组件形式提供，支持 TypeScript。

### Usage

<IconDetailPreview name="Error" category="status" />

```tsx
import { SVG } from '@/registry/components/svg';

<SVG name="general/status/error" />

<SVG name="general/status/error" size="lg" />

<SVG name="general/status/error" aria-label="Error icon" />
```
