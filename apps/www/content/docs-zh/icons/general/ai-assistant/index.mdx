## Overview

来自 JetBrains UI 设计系统的 **16 个 AI Assistant 图标**，以独立 React 组件形式提供，支持 TypeScript。

### Usage

<IconDetailPreview name="AiAssistant" category="ai-assistant" />

```tsx
import { SVG } from '@/registry/components/svg';

<SVG name="general/ai-assistant/aiAssistant" />

<SVG name="general/ai-assistant/aiAssistant" size="lg" />

<SVG name="general/ai-assistant/aiAssistant" aria-label="AiAssistant icon" />
```
