## Overview

来自 JetBrains UI 设计系统的 **18 个 Inline 图标**，以独立 React 组件形式提供，支持 TypeScript。

### Usage

<IconDetailPreview name="Browse" category="inline" />

```tsx
import { SVG } from '@/registry/components/svg';

<SVG name="general/inline/browse" />

<SVG name="general/inline/browse" size="lg" />

<SVG name="general/inline/browse" aria-label="Browse icon" />
```
