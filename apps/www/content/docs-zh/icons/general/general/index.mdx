## Overview

来自 JetBrains UI 设计系统的 **100 个 General 图标**，以独立 React 组件形式提供，支持 TypeScript。

### Usage

<IconDetailPreview name="Search" category="general" />

```tsx
import { SVG } from '@/registry/components/svg';

<SVG name="general/general/search" />

<SVG name="general/general/search" size="lg" />

<SVG name="general/general/search" aria-label="Search icon" />
```
