## Overview

来自 JetBrains UI 设计系统的 **1 个 Spinner 图标**，以独立 React 组件形式提供，支持 TypeScript。

### Usage

<IconDetailPreview name="Loader" category="spinner" />

```tsx
import { SVG } from '@/registry/components/svg';

<SVG name="general/spinner/loader" />

<SVG name="general/spinner/loader" size="lg" />

<SVG name="general/spinner/loader" aria-label="Loader icon" />
```
