## Overview

来自 JetBrains UI 设计系统的 **121 个 Tool Windows 图标**，以独立 React 组件形式提供，支持 TypeScript。

### Usage

<IconDetailPreview name="Terminal" category="tool-windows" />

```tsx
import { SVG } from '@/registry/components/svg';

<SVG name="general/tool-windows/terminal" />

<SVG name="general/tool-windows/terminal" size="lg" />

<SVG name="general/tool-windows/terminal" aria-label="Terminal icon" />
```
