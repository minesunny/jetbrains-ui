## Overview

来自 JetBrains UI 设计系统的 **4 个 Usages 图标**，以独立 React 组件形式提供，支持 TypeScript。

### Usage

```tsx
<SVG name="general/usages/filterdups" />

<SVG name="general/usages/filterdups" size="lg" />

<SVG name="general/usages/filterdups" aria-label="Filterdups icon" />
```
