## Overview

来自 JetBrains UI 设计系统的图标库，以独立 React 组件形式提供，支持 TypeScript。包含 20 个分类，涵盖 General、Tool Windows、Actions、Editor 等。

### Features

- **5 sizes**: `xs` (12px), `sm` (14px), `md` (16px), `lg` (20px), `xl` (24px)
- **Light & Dark** theme variants
- **Accessibility**: `aria-label` and `title` props with proper `role` attributes

## Usage

<IconUsagePreview />

```tsx
import { SVG } from '@/registry/components/svg';

// Basic
<SVG name="general/general/search" />

// With size
<SVG name="general/tool-windows/terminal" size="lg" />

// With accessibility
<SVG name="general/general/search" size="md" aria-label="Search icon" />
```
