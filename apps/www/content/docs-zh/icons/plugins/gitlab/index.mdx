## Overview

来自 JetBrains UI 设计系统的 **2 个 GitLab 图标**，以独立 React 组件形式提供，支持 TypeScript。

### Usage

<IconDetailPreview name="GitLabLogo" category="gitlab" />

```tsx
import { SVG } from '@/registry/components/svg';

<SVG name="plugins/gitlab/gitLabLogo" />

<SVG name="plugins/gitlab/gitLabLogo" size="lg" />

<SVG name="plugins/gitlab/gitLabLogo" aria-label="GitLabLogo icon" />
```
