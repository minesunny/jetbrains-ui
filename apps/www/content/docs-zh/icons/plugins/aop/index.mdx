## Overview

来自 JetBrains UI 设计系统的 **9 个 AOP 图标**，以独立 React 组件形式提供，支持 TypeScript。

### Usage

<IconDetailPreview name="AbstractAdvice" category="aop" />

```tsx
import { SVG } from '@/registry/components/svg';

<SVG name="plugins/aop/abstractAdvice" />

<SVG name="plugins/aop/abstractAdvice" size="lg" />

<SVG name="plugins/aop/abstractAdvice" aria-label="AbstractAdvice icon" />
```
