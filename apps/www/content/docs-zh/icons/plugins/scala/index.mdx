## Overview

来自 JetBrains UI 设计系统的 **55 个 Scala 图标**，以独立 React 组件形式提供，支持 TypeScript。

### Usage

<IconDetailPreview name="AbstractClassObjectScala" category="scala" />

```tsx
import { SVG } from '@/registry/components/svg';

<SVG name="plugins/scala/abstractClassObjectScala" />

<SVG name="plugins/scala/abstractClassObjectScala" size="lg" />

<SVG name="plugins/scala/abstractClassObjectScala" aria-label="AbstractClassObjectScala icon" />
```
