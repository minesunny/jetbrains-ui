## Overview

来自 JetBrains UI 设计系统的 **2 个 Full Line Completion 图标**，以独立 React 组件形式提供，支持 TypeScript。

### Usage

<IconDetailPreview name="FullLineCompletion" category="full-line-completion" />

```tsx
import { SVG } from '@/registry/components/svg';

<SVG name="plugins/full-line-completion/fullLineCompletion" />

<SVG name="plugins/full-line-completion/fullLineCompletion" size="lg" />

<SVG name="plugins/full-line-completion/fullLineCompletion" aria-label="FullLineCompletion icon" />
```
