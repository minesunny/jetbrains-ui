## Overview

来自 JetBrains UI 设计系统的 **112 个 CIDR 图标**，以独立 React 组件形式提供，支持 TypeScript。

### Usage

<IconDetailPreview name="CMake" category="cidr" />

```tsx
import { SVG } from '@/registry/components/svg';

<SVG name="plugins/cidr/cMake" />

<SVG name="plugins/cidr/cMake" size="lg" />

<SVG name="plugins/cidr/cMake" aria-label="CMake icon" />
```
