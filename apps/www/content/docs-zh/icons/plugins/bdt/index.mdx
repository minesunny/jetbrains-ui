## Overview

来自 JetBrains UI 设计系统的 **18 个 BDT 图标**，以独立 React 组件形式提供，支持 TypeScript。

### Usage

<IconDetailPreview name="ArbitraryCluster" category="bdt" />

```tsx
import { SVG } from '@/registry/components/svg';

<SVG name="plugins/bdt/arbitraryCluster" />

<SVG name="plugins/bdt/arbitraryCluster" size="lg" />

<SVG name="plugins/bdt/arbitraryCluster" aria-label="ArbitraryCluster icon" />
```
