## Overview

来自 JetBrains UI 设计系统的 **2 个 GitHub 图标**，以独立 React 组件形式提供，支持 TypeScript。

### Usage

<IconDetailPreview name="Github" category="github" />

```tsx
import { SVG } from '@/registry/components/svg';

<SVG name="plugins/github/github" />

<SVG name="plugins/github/github" size="lg" />

<SVG name="plugins/github/github" aria-label="Github icon" />
```
