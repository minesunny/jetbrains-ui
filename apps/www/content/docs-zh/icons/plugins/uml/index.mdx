## Overview

来自 JetBrains UI 设计系统的 **5 个 UML 图标**，以独立 React 组件形式提供，支持 TypeScript。

### Usage

<IconDetailPreview name="AddNote" category="uml" />

```tsx
import { SVG } from '@/registry/components/svg';

<SVG name="plugins/uml/addNote" />

<SVG name="plugins/uml/addNote" size="lg" />

<SVG name="plugins/uml/addNote" aria-label="AddNote icon" />
```
