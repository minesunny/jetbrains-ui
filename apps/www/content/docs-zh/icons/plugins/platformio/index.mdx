## Overview

来自 JetBrains UI 设计系统的 **6 个 PlatformIO 图标**，以独立 React 组件形式提供，支持 TypeScript。

### Usage

<IconDetailPreview name="Clean" category="platformio" />

```tsx
import { SVG } from '@/registry/components/svg';

<SVG name="plugins/platformio/clean" />

<SVG name="plugins/platformio/clean" size="lg" />

<SVG name="plugins/platformio/clean" aria-label="Clean icon" />
```
